# Contributing

1. One change per pull request. Run `python tools/lg.py validate` before pushing.
2. Every text field needs `de` and `en`.
3. Never add text from purchased standards. Clause numbers only, and only where the
   crosswalk's `publication_status` allows it.
4. Mark editorial content (summaries, questions) clearly; legal text goes only in `text`.
5. Update `verification` when you check content against its source.

By contributing you agree that code is licensed under MIT and content under CC BY 4.0.
