# Security

## What counts

Agents read this repository and act on it. Please report privately:

- content that could steer an agent, for example instructions hidden in a text field of a
  catalog, decision tree or template
- a way to make the tooling or the build run code, read files or reach the network
- a way to get past a rule the tooling enforces, for example a critical triage question where
  "unclear" does not stop
- licensed material that ended up in the repository or its history

Wrong or outdated governance content is not a security issue. Open a normal issue for it.

## How to report

Use GitHub's private reporting: **Security** tab, then **Report a vulnerability**. Please do not
open a public issue for the cases above.

## What to expect

DECAID maintains this repository. Fixes go to `main`; there are no maintained older versions.
